# PawTalk Client 0.16.0 — Демонстрация экрана в звонках

[English](client-v0.16.0.en.md) · [Двуязычный источник](client-v0.16.0.md)

Предварительный выпуск. Изменения относительно Client 0.15.3.

[Windows x64](https://github.com/IlyaRusskikh/PawTalk/releases/download/client-v0.16.0/PawTalk.Setup.0.16.0.exe)

### Добавлено

- Показывайте окно приложения или монитор в голосовом звонке. На поддерживаемых конфигурациях Windows можно передавать звук приложения или системы.
- Смотрите несколько стримов в обзоре, выберите один в фокусе или откройте его на весь экран. Громкость выбранного стрима регулируется отдельно. Предпросмотр у автора остаётся беззвучным.
- Меняйте размер чата в звонке, переносите его вправо или скрывайте. В защищённых чатах удерживайте Shift при нажатии на «Удалить», чтобы удалить сообщение сразу.

### Установка и обновление

Обновите Client или запустите установщик Windows x64. Используйте временную комнату из Client 0.16.0 или обновите постоянный хост до Server 0.15.0. Для просмотра стримов и управления звуком обновите Client зрителей.

## Ограничения

Захват звука приложения доступен на поддерживаемых сборках Windows. В стрим может попасть звук других окон того же приложения. У EXE нет подписи Authenticode.
