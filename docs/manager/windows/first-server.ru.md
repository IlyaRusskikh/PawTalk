# Первый Windows Server

[English](first-server.en.md) · [Установка Windows](installation.ru.md)

1. Откройте Manager после установки. На экране первоначальной настройки выберите **локальный Server ZIP/переносимый пакет** либо явно нажмите **загрузку опубликованного совместимого Server**. Скрытой автоматической загрузки нет.
2. Укажите IPv4-адрес хоста, базовый порт (обычно 18443), лимит истории и настройки обновлений. Проверьте доступность двух публичных TCP и UDP-порта; внутренний порт оставьте закрытым. [Таблица портов](../../server/networking.ru.md).
3. Проверьте параметры и подтвердите установку. Manager проверяет доверенные опубликованные пакеты; локальный импорт требует явного подтверждения. При запросе разрешите регистрацию службы/UAC.
4. Запустите Server и убедитесь, что Manager показывает здоровую работающую службу. Успех HTTP-проверки ещё не подтверждает работу внешнего UDP и голоса.
5. В интерфейсе Manager создайте **приглашение первого администратора**. Откройте полную ссылку `pawtalk://` в совместимом Windows Client; он создаст E2EE root в защищённом локальном хранилище. Начальная ссылка действует 24 часа и расходуется один раз.
6. Проверьте текстовый, затем голосовой канал с другого устройства/сети. Следующие администраторы вступают по обычной ссылке и получают роль от существующего администратора.

Новый Server API 2 не импортирует автоматически членство/backup чата API 1. Не публикуйте начальные ссылки в логах и Issues.
