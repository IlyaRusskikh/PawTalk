# Управление Windows Server через Manager

[English](management.en.md) · [Первый Server](first-server.ru.md)

Windows Manager показывает состояние установленного Server, позволяет запускать/останавливать его и просматривать параметры сети и конфигурации. Server работает как **служба Windows**; закрытие окна не означает удаления серверных данных.

В консоли от имени администратора откройте TUI командой
`& "$env:ProgramData\PawTalk Server Manager\pawtalkctl.exe" tui`. Для установки
с нестандартным каталогом данных укажите `--root <путь>` перед `tui`. Выбирайте
пункты стрелками и Enter или щелчком мыши. Esc возвращает назад. Чтобы остановить
службу перед выходом, выберите **Обзор → Остановить сервер и выйти**.
[Установка на Server Core](installation.ru.md).

В интерфейсе Manager можно проверить установленный пакет/версию Server и состояние службы. Перед сменой адреса или порта учитывайте, что старые приглашения и сохранённые адреса клиентов могут перестать работать; не правьте TLS-идентичность и state вручную.

- **Управление участниками** (каналы, роли, приглашения, кики/баны) выполняется **в Client** администратором/модератором, а не через выдачу прав оператора хоста.
- **Хост-операции** (запуск, остановка, пакеты, обновления, backup) относятся к Manager.
- **Первый администратор** создаётся только до инициализации Server. Нельзя повторно выдать bootstrap-ссылку для восстановления потерянного клиентского E2EE root.

При ошибках подключения проверьте IP и группу портов, брандмауэр Windows, роутер/провайдера и реальную доступность UDP. Не открывайте наружу внутренний порт медиасервера (`PORT+3`). [Сеть](../../server/networking.ru.md).
