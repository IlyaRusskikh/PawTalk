# Обслуживание Windows Server

[English](maintenance.en.md) · [Управление Windows](management.ru.md)

**Резервные копии:** перед изменениями используйте поддерживаемые средства backup Server в Manager и храните копии вне хоста. Сервер сохраняет идентичность, членство и зашифрованный чат, но backup **не содержит** клиентский E2EE root. Без сохранённых устройств/ключей восстановление серверных файлов не расшифрует старое содержимое.

**Обновления:** Client, Server и Manager имеют отдельные подписанные семейства релизов. Проверьте [совместимость](../../server/compatibility.ru.md), создайте копию и выбирайте проверенный совместимый Server в Manager. Обновление приложения Manager само по себе не заменяет Server. Рестарт прерывает звонки; после него проверьте вступление и голос.

**Восстановление:** если установка пакета сорвалась, сохраните журнал транзакции Manager и данные службы для штатного повторения/восстановления. Не удаляйте state, ключи TLS и каталоги служб ради «чистого» запуска. Backup API 1 не является входом восстановления API 2.

В защищённой комнате сохраняйте устройства с более свежими подписанными контрольными точками. Если Client распознает откат политики, он приостановит затронутые отправки. Если осталась только старая копия, её подписи подтверждают состояние на дату копии. Для обнаружения и сверки последующих изменений ролей и отзывов устройств нужны сохранившиеся проверяемые данные новее этой копии.

**Удаление:** заранее решите, нужно ли сохранить серверные данные и копии. Не удаляйте массово системные службы и тома; проверьте принадлежность и используйте штатный деинсталлятор.

Успешный CI на Windows Server 2022/2025 не означает, что точно так же вручную проверены Windows 10/11 и Server 2019. Проверьте свою систему.
