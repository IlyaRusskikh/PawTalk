# Аппаратная приёмка перед выпуском

Не отмечать эти сценарии выполненными по результатам unit-тестов или синтетического микрофона.

## Два Windows-ПК и настоящий сервер

- [ ] Оба клиента входят по IP, паролю и никнейму; одинаковые имена не вытесняют друг друга.
- [ ] Неверный пароль отклоняется; шестая попытка в минуту ограничивается.
- [ ] Оба слышат друг друга; участники и индикация речи появляются/исчезают корректно.
- [ ] Попытки подключиться с повреждённым, просроченным и подписанным чужим ключом JWT отклоняются LiveKit.
- [ ] С валидным пользовательским токеном LiveKit разрешает обмен данными для чата и отклоняет публикацию камеры и экрана. Проверять реальным SDK против сервера, а не только содержимым JWT.

## Аудиотракт и сравнение с Discord

Использовать одинаковые устройства и одну сеть; менять только приложение. Записать модель устройств, Windows build, версии клиента/сервера, настройки обработки. Любую запись запускать вручную с согласия участников.

- [ ] Тихая/громкая речь, начало и конец фраз, шёпот; нет клиппинга и обрезания слогов.
- [ ] Клавиатура, мышь, вентилятор и фоновый разговор. Оценить подавление шума и искажение голоса отдельно.
- [ ] Колонки и одновременная речь: оценить эхо, не пропадает ли собеседник при собственной речи.
- [ ] Ручная/автоматическая чувствительность; при выключенных фильтрах действительно слышна разница.
- [ ] Устройства default и выбранные явно, USB-переподключение, Bluetooth, смена системного устройства.
- [ ] Громкости 0/100/200%, индивидуальный mute и deafen.
- [ ] Тест микрофона прекращает захват при остановке и переходе к подключению.

## PTT и системные функции

- [ ] Каждая выбранная клавиша: press/release, удержание, потеря фокуса, смена режима, изменение клавиши во время удержания.
- [ ] Боковые кнопки мыши; игра в оконном/полноэкранном режиме; отдельно игра с повышенными правами и античитом.
- [ ] В PTT до нажатия, после задержки отпускания и при mute отсутствует слышимая речь. Служебные RTP/DTX-пакеты могут оставаться — это не утечка микрофона.
- [ ] Mute/deafen в фоне; занятая комбинация выдаёт сообщение.
- [ ] Приглушение собственной/чужой речью, переключение силы, новые запущенные приложения и разные аудиовыходы.
- [ ] Уровни восстанавливаются после отключения приглушения, выхода из комнаты, штатного закрытия и зависания renderer более двух секунд.
- [ ] Ручное изменение системной громкости во время приглушения не откатывается к старому значению.
- [ ] Принудительное убийство процесса: оценить известное ограничение восстановления; при необходимости сделать внешний watchdog до распространения.

## Сеть, нагрузка и задержка

- [ ] UDP напрямую; блокировка UDP с переходом на TCP; 1/3/5% потерь и переменный джиттер.
- [ ] Краткий обрыв сети: SDK переподключается. Долгий обрыв, рестарт сервера и сон: понятное состояние и повторный вход без перезапуска клиента.
- [ ] 30 соединений; отдельно 10 одновременно говорящих. Зафиксировать CPU/RAM сервера и клиента, сеть, потери и слышимые артефакты за 30 минут.
- [ ] Измерить полную одностороннюю задержку контрольным сигналом и записью входа/выхода с общей временной базой. Сохранить p50/p95 не менее 100 измерений отдельно для LAN и реальных маршрутов.
- [ ] Повторить с Discord и при игровой нагрузке. Не подменять измерение голоса сетевым RTT.
- [ ] Заранее численную гарантию задержки не заявлять. По результатам согласовать целевые p50/p95 и решить, нужен ли нативный аудиодвижок.

## Развёртывание и установщик

- [ ] Постоянный сервер на чистом Linux: готовый образ 0.5.2 → Docker Swarm → HTTPS healthz → два клиента по актуальному приглашению. Порядок: [SERVER.md](SERVER.md).
- [ ] Проверены публичные TCP 18443/18444 и UDP 18445 (либо заданный порт и смещения +1/+2); внутренний LiveKit API 18446 не открыт извне.
- [ ] Перезапуск контейнера сохраняет данные и TLS-идентичность; неверный отпечаток сертификата в приглашении отклоняется клиентом.
- [ ] Встроенная Windows-комната: два клиента в LAN, затем гость из другой сети; закрытие хоста завершает комнату, новое приглашение работает после пересоздания.
- [ ] Windows x64: установщик, запуск без Node.js, нативный модуль загружен, трей и удаление приложения.
- [ ] Конфигурация/логи/пакет не содержат открытого пароля или LiveKit-секрета.

Старое развёртывание через `configure`/Caddy проверяется отдельно, если оно
используется: внешние 8080/7880 закрыты, публичный сертификат выдан и продлевается,
Caddy data сохраняется. Это не обязательный шаг установки готового 0.1.0-сервера.
