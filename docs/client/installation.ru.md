# Установка Windows Client

[English](installation.en.md) · [Документация](../README.ru.md)

1. Откройте [страницу загрузки Client](https://ilyarusskikh.github.io/PawTalk/downloads/#client). Выберите **опубликованный Windows-установщик** семейства Client, а не архив исходников и не пакеты Server/Manager.
2. Скачайте установщик и контрольные суммы **того же релиза**. Проверьте SHA-256 в PowerShell (подставьте имя файла):
   `Get-FileHash -LiteralPath "PawTalk.Setup.VERSION.exe" -Algorithm SHA256`
3. Сравните результат с `SHA256SUMS.txt` из этого выпуска. При несовпадении не запускайте файл. Контрольная сумма подтверждает целостность относительно опубликованного значения, но не заменяет цифровую подпись Authenticode или аудит.
4. Установите приложение. При первом запуске укажите имя, микрофон и устройство вывода.

Сейчас установщик не имеет подписи Authenticode, поэтому Windows может предупредить о неизвестном издателе. Перед запуском проверьте источник и хеш.

**Обновления:** используйте интерфейс обновления Client либо установите новый опубликованный Client поверх предыдущего. Client, Server и Manager выпускаются **независимо**. Обновление клиента не обновляет постоянный сервер. [Совместимость](../server/compatibility.ru.md).
