# Справочник настроек

[English](settings.en.md) · [Документация](../README.ru.md)

Настройки PawTalk сгруппированы по назначению:

| Раздел | Что настраивается |
| --- | --- |
| Профиль | Имя и аватар |
| Аудио и устройства | Выбор микрофона и динамиков, уровни, проверка микрофона, режим ввода, PTT, RNNoise, эхоподавление и усиление |
| Звуки | Уведомления, громкость и прослушивание встроенных звуков |
| Оформление и чат | Тема и цвета, шрифт, интервалы, представление сообщений |
| Система | Автозапуск Windows, трей, горячие клавиши, обновления Client |

Эти настройки хранятся локально и **не являются настройками Server Manager**. Лимит истории, адрес и обновления постоянного сервера задаются через его Manager. Версии Client, Server и Manager независимы.

При проблемах с микрофоном сначала проверьте системные разрешения и устройства, а уже потом меняйте чувствительность. Если пункт отсутствует или ведёт себя иначе, проверьте [описания опубликованных выпусков](../../releases/README.ru.md), а не невыпущенный исходный код.
