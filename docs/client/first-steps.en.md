# Your first conversation

[Русский](first-steps.ru.md) · [Documentation](../README.md)

1. Install the [Windows Client](installation.en.md) on both computers. In the first-run guide, choose a nickname, input device and output device.
2. On the host computer select **Create server**, set its name and wait for the temporary server to start. The creator becomes its administrator. Alternatively, use a permanent server prepared by its administrator.
3. Open the server's **Invite participants** action. Create a timed invitation and share the **complete** link privately. The recipient chooses **Join server** and pastes the link.
4. After joining, select a **voice channel**. Joining the server itself does not open the microphone. On both computers, check mute, Push-to-Talk or voice activation, selected devices and output levels.
5. Exchange a message in a text channel to confirm membership and messaging. Test voice from two actual devices, not only from one computer.

For a temporary server, history is held in memory until it stops. Internet access needs reachable ports and may be blocked by CGNAT or the router. [Network guide](../server/networking.en.md) · [Troubleshooting](troubleshooting.en.md).

**Security:** invitations contain sensitive admission/key material. Do not paste them into public issues, logs or screenshots.
