# Windows Client: назначение и возможности

[English](overview.en.md) · [Документация](../README.ru.md)

PawTalk Client — **приложение для голоса и чатов в Windows x64**. Оно создаёт временный сервер на компьютере или подключается к постоянному серверу. Центральный аккаунт не требуется.

На сервер можно вступить без автоматического подключения к голосу. Членство сохраняет сервер в боковой панели; текстовые каналы содержат сообщения, изображения, ответы и список участников. В голосовой канал входят отдельно. В клиенте есть PTT, активация голосом, обработка микрофона и персональная громкость собеседников.

Администратор управляет каналами, ролями и приглашениями; модератор может выдавать и отзывать свои приглашения. Устройства можно связать в группу на одном сервере, но одновременно говорить разрешено только одному устройству группы.

**Ограничения:** API 2 несовместим со старым API 1. Голос, текст и вложения используют E2EE, но оно не скрывает сетевые метаданные и не отзывает уже доставленные копии. Windows Client распространяется как preview.
