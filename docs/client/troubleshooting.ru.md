# Решение проблем Client

[English](troubleshooting.en.md) · [Документация](../README.ru.md)

| Симптом | Что проверить |
| --- | --- |
| Не получается вступить | Полное действующее приглашение, API 2 сервера, доступный адрес, отпечаток TLS-сертификата и сеть |
| Сервер доступен, голоса нет | Вход в голосовой канал, mute/deafen, устройства, PTT/активацию голосом, громкость |
| В LAN работает, из интернета нет | CGNAT, брандмауэр, проброс обоих TCP и UDP, затем звонок из другой сети |
| Локальная ссылка не работает снаружи | Внешний адрес в приглашении; сохраните верные TLS-отпечаток и секретный фрагмент |
| Ошибка несовместимости | API 1 не работает с API 2; выберите опубликованные совместимые выпуски |
| Нет доступа к содержимому чата | Членство, состояние ключей/устройств; backup сервера не содержит клиентский E2EE root |

Не отключайте проверку отпечатка или E2EE ради обхода ошибок. В [GitHub Issues](https://github.com/IlyaRusskikh/PawTalk/issues/new/choose) сообщайте **обезличенные** симптомы и теги выпусков, но не действующие приглашения, ключи и личные сетевые данные.
