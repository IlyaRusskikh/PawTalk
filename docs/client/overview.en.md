# Windows Client: what it does

[Русский](overview.ru.md) · [Documentation](../README.md)

PawTalk Client is the **Windows x64 voice and text application**. It can run a temporary local server or connect to a permanent one. It requires no central account.

You can join a server without entering its voice channel. Membership keeps the server in your sidebar; messages, images, replies and online participants are available through its text channels. Voice channels are entered separately. The client offers Push-to-Talk, voice activation, microphone processing and individual participant volume.

Administrators manage channels, roles and invitations. Moderators can create and revoke their own invitations. A server can include linked devices, but only one device in a linked group may use voice at once.

**Limits:** API 2 is a breaking change; historical API 1 servers are not compatible. Voice, text and attachments require E2EE, but E2EE does not hide network metadata or revoke copies already delivered. The published Windows Client is a preview.
