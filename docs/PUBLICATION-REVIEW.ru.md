# Проверка перед первой публикацией

Состояние на **5 ноября 2026**, версия **0.1.0**. Исходники подготовлены к первой
загрузке на GitHub. Проверка не означает независимый аудит безопасности или
подтверждение всех аппаратных и сетевых сценариев.

## Состав и конфиденциальность

- В Git входят исходники клиента, сервера и нативного модуля, ресурсы интерфейса,
  фиксированные зависимости, тесты, инструкции и лицензии.
- Локальные серверные настройки и ключи, личные заметки, диагностические отчёты,
  записи, зависимости и готовые сборки исключены через `.gitignore`.
- `scripts/check-public.mjs` проверяет индекс и рабочие файлы отдельно,
  подозрительные ключи/токены/приглашения, запрещённые пути и размер файлов.
  Проверено, что незакоммиченное исправление не скрывает секрет, уже добавленный
  в индекс. Значения ключей и хеша пароля из локальных env-файлов не обнаружены
  точным сравнением в публикуемых исходниках.
- Документация использует примеры адресов; локальный публичный IP из теста заменён
  адресом для документации. Перед каждым push всё равно нужно просматривать diff.

## Что проверено

- TypeScript/Vite build и **41 JS-тест**.
- Go: `go test ./...`, `go vet ./...`.
- Нативная Windows-сборка через LLVM и проверка загрузки/глобальных hooks.
- UI-flow: подключение, диалоги, закладки и настройки.
- Renderer smoke с синтетическим микрофоном: AudioWorklet, мониторинг,
  шумоподавление, чувствительность, смена устройств и остановка захвата.
- Сборка NSIS-установщика и запуск упакованного Windows-приложения:
  изолированный preload, native resource, RNNoise, запрет plaintext HTTP,
  встроенная комната, копирование выбранного приглашения, TLS и вход по паролю.
- AGPL и runtime notices внутри `app.asar` совпадают с текущими файлами проекта.
- Docker-образы API и постоянного сервера собираются с файлами лицензий.
  Lifecycle smoke проверил TLS, пароль, перезапуск, сохранение данных и остановку.
- Отдельная копия только публикуемых исходников прошла `npm ci`, build и 41 тест
  без локальных конфигураций и готовых сборок (4 ноября).
- Локальные Markdown-ссылки и отсутствие ошибок whitespace в diff.

В прежнем запуске packaged smoke наблюдалась остановка встроенного API.
После перезагрузки 5 ноября сценарий прошёл с диагностикой и без неё; причина
прежнего завершения не установлена. Тест сохраняет stderr при ошибке,
явно останавливает комнату и дожидается завершения тестового приложения.
Это поведение нужно наблюдать при аппаратной приёмке.

## Зависимости и ограничения

`npm audit` 5 ноября: **0 high/critical**, **15 moderate** в инструментах сборки,
связанных с одним [advisory minimatch](https://github.com/advisories/GHSA-g3hv-75wg-m249).
В production-дереве затронутых пакетов не найдено. Автоматическое исправление
предлагает несовместимую смену electron-builder; оно не применено. Обновление
цепочки сборки требует отдельной проверки упаковки.

Удалённый GitHub Actions, MSVC на чистом компьютере, чистая установка Windows,
реальные микрофоны/PTT в играх, соединение между разными внешними сетями и
нагрузка до 30 участников здесь не подтверждены. Установщик не подписан,
автообновления не настроены. См. [ACCEPTANCE.md](ACCEPTANCE.md).
