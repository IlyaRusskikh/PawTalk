# PawTalk Server: временный или постоянный?

[English](overview.en.md) · [Документация](../README.ru.md)

**Временный сервер:** запускается Windows Client на общем серверном ядре. Создатель становится администратором. Состояние и история чатов хранятся в памяти и пропадают после остановки хоста. Подходит для коротких встреч друзей; компьютер ведущего должен оставаться включённым.

**Постоянный сервер:** работает независимо в Windows (нативная служба) либо Linux (Docker Compose под управлением Manager). Членство и зашифрованные сообщения сохраняются в SQLite вместе с конфигурацией. Устанавливайте через соответствующий [Windows Manager](../manager/windows/installation.ru.md) или [Linux Manager](../manager/linux/installation.ru.md).

Оба режима поддерживают опубликованный API 2, каналы, приглашения, E2EE и роли. Client, Server и Manager обновляются отдельно. Загружайте их из соответствующих семейств опубликованных релизов; автоматической миграции старых установок API 1 нет.

В отличие от сервиса с единым аккаунтом, членство действует внутри конкретного PawTalk Server. Владелец отвечает за доступность, сетевые правила, резервные копии и управление участниками.
