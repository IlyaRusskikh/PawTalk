# Участники, роли и приглашения

[English](administration.en.md) · [Документация](../README.ru.md)

На сервере есть роли **администратор**, **модератор** и **участник**. Администратор управляет каналами, ролями, киками/банами и приглашениями. Модератор создаёт приглашения и отзывает свои. Права сейчас действуют на весь сервер, а не на отдельные приватные каналы.

**Первый администратор постоянного сервера:** в Windows Manager есть начальное приглашение; в Linux выполните `sudo pawtalkctl initial-admin --url`. Одноразовая ссылка действует 24 часа и выдаётся только до первоначальной инициализации. Первый Client создаёт E2EE root и сохраняет его в защищённом хранилище ОС; Manager/Server не получают корень в открытом виде. Следующий администратор вступает по обычной ссылке и получает повышение от действующего.

**Обычные приглашения:** одноразовое действует 24 часа, многоразовое — час; лимит — 100 активных приглашений каждого типа на сервер. Истечение ссылки не исключает уже вступивших. Полные ссылки передавайте приватно.

Удаление участника запрещает новые авторизованные операции API, но **не** меняет общий корневой ключ и не уничтожает ранее полученные ключи/копии. Удаление текстового канала необратимо удаляет сохранённую историю и вложения. [Архитектура безопасности](../../architecture/security.ru.md).
