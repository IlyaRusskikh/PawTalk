# 014. Превью и версии медиа для просмотра

[English](014-media-variants.en.md)

Стенд на Windows Electron сравнил исходное поведение, статичные превью и превью с отдельной версией для просмотра. Для 36 фото по 1,87 МБ трафик при прокрутке снизился с 67,43 до 1,27 МБ за счёт превью. При имитации соединения 25 Мбит/с копия в 0,59 МБ сократила открытие фото примерно с 0,72 до 0,31 с. Имеющиеся постеры уже обеспечивали плавную прокрутку видео. Пробное кодирование занимало примерно столько же времени, сколько длится видео, поэтому Client воспроизводит исходные ролики.

Статичные превью создаются по умолчанию с ограничением размера. Копия для просмотра создаётся для большого статичного фото, если она занимает до половины исходника и укладывается в текущую квоту вложений. Исходные байты сохраняются. Если размер исходника — `S`, размер копии — `V`, а `M` — число открытий с загрузкой из сети, добавочный трафик относительно схемы только с превью равен `V − M × (S − V)` байт. Потребление хранилища увеличивается на `V` байт. При выборе порога также учитывается время подготовки и отправки.

Стенд использует рабочие компоненты интерфейса, синтетические файлы и имитацию передачи. Он замеряет прокрутку и время открытия, а проверка зашифрованных вложений покрывает доступ и сохранность байтов. См. [контракт медиа](../../architecture/chat-features.ru.md#версии-медиа).
