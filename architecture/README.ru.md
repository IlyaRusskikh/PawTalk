# Архитектура PawTalk

[English](README.md) · [О проекте](../README.ru.md) · [Документация](../docs/README.ru.md)

Раздел описывает технические контракты **опубликованного семейства API 2**. Код `main` может быть новее опубликованного тега: совместимость production определяйте по неизменяемым тегам каждого компонента.

- [Обзор](overview.ru.md) — компоненты, ответственность, схема запуска
- [Карта компонентов](components.ru.md) — владельцы кода и точки входа
- [API](api.ru.md) — идентичность, вступление и семейства endpoint
- [База данных](database.ru.md) — SQLite schema 2 и жизненный цикл
- [Безопасность](security.ru.md) — аутентификация, E2EE, доверие и ограничения
- [Сеть](networking.ru.md) — границы транспорта и порты
- [Аудио](audio.ru.md) — тракт, обработка, шифрование
- [Доверие к обновлениям](updates.ru.md) — версии, манифесты, подписи
- [Разработка](development.ru.md) — сборка и локальная среда
- [Проверки](verification.ru.md) — уровни тестов и подтверждённые утверждения
- [Выпуск релизов](releasing.ru.md) — независимые кандидаты и публикация

Точные контракты задают [реализация сервера](../server/), [SQL-схема](../server/membership.sql), [Client](../src/) и [исполняемые тесты](../tests/). Эти документы — поддерживаемая карта, **а не** замена проверке исходников.

- [Новые функции чата](chat-features.ru.md) — необязательные capabilities, шифрование аватаров/опросов, метаданные упоминаний и активности (исходный код).

- [Аудит соединений](connection-audit.ru.md) — события, сохраненные опросы и границы проверки.
