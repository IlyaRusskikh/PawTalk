# PawTalk notification sounds

Eleven phone recordings supplied by the project owner, featuring their cat Manya (Маня). Distributed with PawTalk under AGPL-3.0-only. Audio is unchanged; filenames use ASCII.

- room-join.wav / room-leave.wav: room entry / exit.
- mute.wav / unmute.wav: microphone off / on.
- deafen.wav / undeafen.wav: incoming audio off / on.
- message-purr-01.wav through message-purr-05.wav: five message variations.

Only recordings from the action folders are included. The future mention cue and unassigned recordings are excluded. See sources.json for SHA-256 checksums.
