# PawTalk notification sounds

- `room-join.wav`: approved CC0 variant B, edited from
  [Meow Cat #13](https://bigsoundbank.com/meow-cat-13-s1901.html).
  Short "mya-myau" with a higher second syllable, 0.752 seconds.
- `room-leave.wav`: approved CC0 variant A, edited from
  [Meow Cat #2](https://bigsoundbank.com/meow-cat-2-s1890.html).
  Single meow with gently falling pitch, 0.750 seconds.
- `message-purr-01.wav` through `message-purr-05.wav`: five excerpts of
  [Cat Purr #0436](https://bigsoundbank.com/cat-purr-s0436.html) by Joseph SARDIN /
  BigSoundBank, released under CC0. Each has a 120 ms attack and 240 ms fade-out.

All seven recordings are edits of works by Joseph SARDIN / BigSoundBank,
dedicated under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
They may be copied, modified and redistributed with the application and source.
The earlier user-provided Uppbeat/Pixabay meows are not used in this build.

See `sources.json` for individual asset checksums and provenance. No original
downloads, personal recordings or audio-processing tools are packaged.
