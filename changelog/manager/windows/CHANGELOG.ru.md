[English](CHANGELOG.en.md) · [Индекс](../../README.ru.md)

Один тег Manager относится к Windows и Linux. Платформенные разделы ниже — часть документации, **а не отдельные версии**.

## manager-v0.7.2

Manager обновляет работающую комнату API 3 с Server 0.14.1 до подписанного Server 0.15.0. При сбое Manager восстанавливает предыдущую версию Server вместе с данными комнаты.
