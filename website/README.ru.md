# Сайт PawTalk

[English](README.md) · [Документация](../docs/README.ru.md)

Статический лендинг на русском и английском. Страница [загрузок](https://ilyarusskikh.github.io/PawTalk/downloads/) показывает опубликованные выпуски Client, Server, Manager через динамический каталог GitHub Releases. Не создавайте вручную ссылки на будущие версии или общий /releases/latest.

Деплой выполняется через Pages после фактической публикации или явного запуска с main; без публикации не следует показывать выдуманный релиз. Проверка сайта: `node scripts/check-website.mjs`; для каталога — генерация `node scripts/release-catalog.mjs` и `node scripts/check-website.mjs --catalog`.

Скриншоты в assets относятся к **историческому интерфейсу 0.7.x** и не доказывают внешний вид текущего API 2. Перед заменой снимков соберите и проверьте опубликованный клиент, обезличьте данные и перепроверьте оба языка.
